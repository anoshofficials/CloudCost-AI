|---------|-----------|

---

## Reporting a Vulnerability

We take the security of CloudCost-AI seriously.

If you discover a security vulnerability, please report it privately instead of creating a public GitHub issue.

### Contact

Email: cloudcost.ai5@gmail.com

### Please Include

- A clear description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Screenshots or proof of concept (if applicable)

### Response Timeline

- Initial acknowledgement: Within 48 hours
- Investigation: Within 3–7 business days
- Security updates: Based on the severity of the issue

We appreciate responsible disclosure and will work to resolve confirmed vulnerabilities as quickly as possible.

Thank you for helping keep CloudCost-AI secure.
